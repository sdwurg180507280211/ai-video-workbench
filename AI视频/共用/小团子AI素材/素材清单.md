# 小团子AI 素材库

账号角色「小团子AI」的贴纸。`透明/` 是透明底 PNG（最长边 800，可直接叠进视频），`原图/` 是生图网关出的原图（浅蓝纯色底，1254×1254）。
角色长相以 `参考_角色A.png` 为准；新出素材时把它当参考图传给 `images/edits`，背景要求纯色浅蓝 #DCE8FA，再用 `抠图.py` 抠透明。

用户偏好：不要红底，不要回车键元素。

## 放进代码动画

在片子的 `index.html` 里当 SVG 图片用，路径相对工程根目录（先把要用的 PNG 复制到工程的 `assets/xiaotuanzi/`）：

```js
el('image', { href: '/assets/xiaotuanzi/03_疑惑.png', x: -200, y: -200, width: 400, height: 400 }, g);
```

宽高按 PNG 的实际比例写，不然会被拉伸。
