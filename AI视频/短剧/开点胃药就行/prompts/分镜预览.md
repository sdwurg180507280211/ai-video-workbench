# 分镜预览图提示词

用途：开拍前审画面（构图、站位、人群、会露字的道具、每格能看清的脸数），**不传给视频模型**，所以不受写实人脸审核限制。每段一张，画那一段最关键的一个镜头。人物的脸只是占位，正式片里用定妆照和真人人像。

生成：生图网关 `gpt-image-2.5-sunburst`，`size`/`quality` 都是 `auto`；第一段是公共部分，后面每段一个代码块，按顺序对应 S1～S13。

## 公共部分

```
写实的电影剧照风格分镜预览图，竖构图（画面竖长，9:16），像纪录片摄影师手持跟拍时的一帧：平视，日光灯原本偏冷的白光，不调电影色，自然肤色，皮肤哑光，真实质感，略有景深。
地点：中国一家三甲医院消化内科门诊的诊室，工作日上午。诊室不大：一张医生办公桌，桌上两台电脑显示器（屏幕朝着医生，镜头只看到显示器背面或侧面）、一台小打印机、一个保温杯；桌边一把给病人坐的椅子；靠墙一张检查床，拉着浅蓝色帘子。诊室门开着一半，门外是走廊，候诊的人很多，走廊里的人只露背影或被门框挡住大半。
只画"本格画面"里写到的人和道具，本格没写到的人一律不要出现在诊室里，也不要把下面某个人物的道具画到别人手上。下面是人物的样子，供本格出场时参照：
医生：三十岁左右的中国男性，短发，白大褂敞着，里面浅蓝色衬衫，不戴口罩，左胸口袋上别着一个很小的工牌，看不清字。
研究生：二十四五岁的中国女性，低马尾，细框眼镜，白大褂，胸前的小工牌看不清字。
周建国：五十二岁的中国男性，偏胖，寸头，深色旧夹克，衣服上没有字和标志。
妻子：五十岁左右的中国女性，短烫发，斜挎包，手里提着一个白色不透明的塑料袋（这个塑料袋只属于她）。
画面里没有任何可读的文字、数字、标志或水印：显示器、单子、药盒、手机、门牌都背对镜头、出画或被遮挡。不要字幕，不要编号，不要边框，不要拼图，一张图只画一个画面。
```

## 每段的画面

S1 开场：网上查的
```
中近景。一位五十岁左右烫短发、穿着外套的大姐坐在医生桌边，身子往前探，手里只攥着手机（没有拎袋子），手机屏幕背对镜头，神情着急。医生坐在桌后，从电脑前转过身来看着她，神情平和。研究生在医生侧后方低头打字。背景里诊室门开着一半，门外走廊人很多，只看到背影。
```

S2 来开药的大爷
```
中景。一位七十岁左右的老大爷坐在病人椅上，把一个空药盒放在桌上，药盒印字的面朝下。医生看着大爷，像在问话。大爷手边放着一个旧布袋。画面里只有大爷和医生两个人。
```

S3 门口
```
从诊室里面朝门口拍，镜头前景是空的。画面里只有两个人：一个二十多岁的年轻小伙扒着门框探进半个身子，手里举着一张报告单，报告单背面朝镜头；门边站着一位戴口罩、穿护士服、不戴护士帽的分诊护士，抬起一只手示意他先出去等。门外走廊挤满候诊的人，只露背影。诊室里没有医生、没有研究生、没有病人。
```

S4 叫到周建国
```
从诊室里面朝门口拍。门被推开，周建国一只手按着上腹走进诊室，妻子提着白色塑料袋跟在他身后。前景是医生的背影和肩膀（只看到后脑勺和白大褂，不露脸），他正抬头看向进门的人。
```

S5 他吃的药
```
中景，三个人：周建国坐在病人椅上，妻子站在他椅子后面，一只手搭着椅背，另一只手把白色塑料袋的袋口敞开、朝着医生；镜头只看到袋子外侧，看不到袋子里面。医生在桌后微微探身，往袋子里看。
```

S6 问诊
```
中景，从医生侧后方斜拍过去：医生看着周建国，平常地问话；周建国坐在病人椅上回答，神情放松；妻子站在他身后听着。显示器只露背面边缘。
```

S7 不做不做
```
中景：周建国坐在椅子上往后一靠，抬起一只手轻轻摆了一下，表示不想做；表情是不情愿但不夸张。医生坐在桌后，神情平静，没有着急。妻子站在周建国身后。
```

S8 无痛，和钱
```
中近景，从周建国肩后拍医生（周建国只露肩膀和后脑勺）：医生一边说话一边微微摊开一只手，像在讲两个选择，神情认真、耐心。妻子站在一旁看着医生。
```

S9 开出租的
```
中景，画面里只有三个人：周建国坐在病人椅上，有点犹豫；妻子站在他旁边，侧过头看着他，语气心疼地跟他说话；医生坐在桌后看着他们，安静地等，没有催。研究生不在画面里。三个人之间没有肢体接触。
```

S10 开单
```
特写，只拍桌面：医生的一只手搭在鼠标上，准备点确认；旁边的小打印机正在出一张纸，纸的背面朝镜头。显示器不在画面里。画面里不露任何人的脸。
```

S11 交代
```
中景：研究生站在桌边，把一张刚打印的单子递给妻子，单子背面朝镜头；她看着周建国和妻子两个人说话。周建国坐着，妻子伸手接单子。医生不在画面里。
```

S12 中午了
```
中景，画面里只有三个人：医生坐在桌后，拿着保温杯喝了一口水；研究生在他旁边看着电脑屏幕（屏幕背对镜头）；诊室门口探进来一位戴口罩、穿白大褂的中年女医生，像在跟医生打招呼。上一个病人刚走，诊室里此刻没有病人，病人椅是空的。时间是中午，门外走廊的人少了一些。
```

S13 门诊结束以后
```
近景：门诊结束了，诊室里只剩医生一个人，他坐在桌边，身体放松，看着镜头，像纪录片里补拍的采访。身后的诊室门开着，门外走廊空了，安静下来。灯光和前面一样是日光灯。
```
