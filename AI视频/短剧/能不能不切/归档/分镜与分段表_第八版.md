# 《先听她说》第八版 · 分镜与分段表

2026-10-21。先按人物的说话策略与反应安排镜头，再拆成15个4–12秒的生成批次，共118秒、28个镜头。118秒是首轮生成预算，最终剪辑依表演收紧；本版未生成、未听读验证，不把旧视频当作本版。

开场他求医生给确定答案 → 她问生育 → 他再次替她决定 → 她把话接回来 → 两人听见彼此害怕 → 她拿出早准备好的问题 → 走廊提出新约定并主动牵手。

摄影只在主对话轴线同一侧，详见《连戏表.md》。景别与切镜服务于正在争取什么：不逐句机械反打；两句“怕”保持双人同框，结尾收手与牵手各有完整动作。未标运镜即固定观察，不额外推拉。医生以目光、回应和留时间建立魅力，眉间舒展，音量平常。
