# 代码动画制作流程

> 给新接手的 AI：一支代码动画从定题到出片怎么做、东西放在哪。细节以 opus-code-video Skill 为准，这一页只把散在各处的入口串起来。

## 开工前

- **Skill**：Mac `~/ideaProjects/my-skills/skills/opus-code-video/`。先读 SKILL.md 和 `references/` 三篇；`render-and-qc.md` 末尾的教训，每支片开工前都要对一遍。Claude Code 里看不到这个 Skill 时，在 my-skills 目录运行 `python3 scripts/link_skills.py --apply`。
- **工程和素材**：都在 Mac 的 `~/Downloads/AI视频/`，先读那里的 `先读我.md`。这个仓库只放剧本和审稿记录。
- **从 Windows 经 SSH 操作 Mac**：非交互 shell 里没有 node 和 ffmpeg，先运行 `export PATH=/usr/local/bin:$HOME/.nvm/versions/node/v24.13.1/bin:$PATH`。
- **密钥**：只存在 Mac 本机，不贴进对话，也不进仓库。

| 用途 | 在哪 |
|---|---|
| 旁白（豆包语音 2.0） | `~/.config/volc-speech/api-key` |
| 剧本审稿（DeepSeek） | `~/.config/deepseek/api-key` |
| 贴纸、封面插画（生图网关，免费） | 地址、调用方法和教训见 `~/.ai-global/IMAGE_GATEWAY.md`；Key 在 `~/.config/image-gateway/api-key` |

## 步骤

1. **定题**：发在哪、给谁看、片长多少。同一系列沿用前作的设定：贴纸科普风格、横屏 16:9、旁白用童声「软萌团子」（语速 -4）、逐句字幕。
2. **剧本**：写在本仓库 `AI视频/代码动画/<片名>/剧本.md`，包括定位、"这一支要比前几支好在哪"（对照教训来写）、旁白表（时间、段落、画面、旁白）和事实边界。
3. **审稿**：在 Mac 上运行
   `python3 ~/ideaProjects/my-skills/skills/seedance-short-drama/scripts/review_script.py 剧本.md --context "纯代码逐帧渲染的贴纸科普，没有视频模型的单段时长限制……" --out 审稿/审稿_DeepSeek_第N轮.md`
   - 复查时加 `--prev 审稿/<上一轮>.md`。
   - 每条意见都标出处，并给出采纳、改着采纳或驳回的建议，写进剧本末尾的「审稿」一节，交用户批；用户批了才改。
   - 一直改到两路都是"必须改：无"。版权、合规类意见默认不采纳。
   - 剧本没定稿，就不建工程、不配音。
4. **建工程**：
   `MG_STYLES_DIR=~/ideaProjects/mg-styles-15 bash ~/ideaProjects/my-skills/skills/opus-code-video/scripts/new_project.sh ~/Downloads/AI视频/代码动画/<片名>`
   - 运行前先把 `.venv` 和 `node_modules` 软链接到《按下回车之后》工程，可以省掉安装。
   - 最新的写法以《一个字一个字》工程为准（如 `film/build_cues.py`、`cover_gw.py`），从那里复制过来改。
5. **配音**：`voice/旁白.txt` 每行一句，用户确认过的文字才能合成。命令：`python3 …/opus-code-video/scripts/doubao_tts.py lines <音色ID> <工程> --rate -4`。新账号送 2 万字，超出后每万字 3 元，超额前要先报价。
6. **排节拍**：先运行 `film/build_cues.py`，按每句的说话时长定每段长度，画面事件钉在旁白的词上；再运行 `retime.py <工程>` 补上字幕。画面和配乐都只读 `film/cues.json`。
7. **画面**：写在 `film/index.html`。先出 6～10 张关键帧逐张检查，没问题再渲染整片。
   - 小团子缺的动作用生图网关出贴纸：参考图加纯色浅蓝底，抠图后收进 `共用/小团子AI素材/`，并登记到素材清单。
8. **配乐与混音**：先 `.venv/bin/python film/audio.py`，再运行 `mix_voice.py <工程>`。
9. **渲染与质检**：
   - 渲染：`node harness/render.mjs film --mb 8 --workers 4`，2 分钟的片约 17 分钟。
   - 检查：运行 `qc.py`，每 1～2 秒抽一帧拼成总览图看节奏。
   - 自评最弱的三点，写进 `render-and-qc.md` 的教训。
10. **交付**：
    - 成片 `<片名>_v1.mp4`。
    - 封面横 4:3、竖 3:4 各一张：插画版用网关画图，再用 `cover_gw.py` 叠标题。
    - 发布用的标题和简介。
    - 收尾：更新工程的 `作品.json`（状态只写 进行中 / 暂停 / 已完成），写工程的 `交接.md`，更新本仓库 `AI视频/README.md` 的作品表。

## 规矩

- 花钱的事先报价，网关和渲染都不花钱。
- 旁白和字幕的文字改动都要用户确认。例外：每日定时任务（[云端/每日定时任务.md](云端/每日定时任务.md)）经用户授权全自动，用 DeepSeek 审稿代替用户审批。
- 故事类片子（如睡前故事）反过来做：先做无声版（画面 + 配乐 + 音效），静音也能看懂，再定配音。见《小王子与狐狸》的改稿记录。
- 过时的东西直接删，不留旧版本。
