## 怎么跑

```bash
export PATH=/usr/local/bin:$HOME/.nvm/versions/node/v24.13.1/bin:$PATH   # ssh 非交互 shell 里没有 ffmpeg/node
S=~/ideaProjects/my-skills/skills/opus-code-video/scripts
python3 film/build_cues.py && python3 $S/retime.py .
node harness/render.mjs film --stills 2,15,24,31,47,56,72,82,88,92,95,102   # 关键帧 → film/out/stills/
.venv/bin/python film/audio.py && .venv/bin/python $S/mix_voice.py .
node harness/render.mjs film --mb 8 --workers 4                              # 整片 → film/out/video.mp4
```

- 节拍只改 `film/build_cues.py`：画面事件都钉在旁白的词上。画面 `index.html` 和配乐 `audio.py` 都只读 `film/cues.json`。
- `render.mjs` 不认 `--help`，带了不认识的参数会直接开始整片渲染。

## 画面做法要点

- **雪花和图都画在 canvas 里**：canvas 放在 SVG 的 `foreignObject` 里，每帧同步重画。没用 `<image>` 加 dataURL，是为了避免截图时图片还没解码完。
- **雪花**：`noise(seed)` 用固定种子，同一个种子永远是同一屏雪花，第⑤章就靠这一点。
- **图**：
  - `catScene`：A 是坐着，B 是趴着；`scarf:false` 是没戴围巾；`style:'high'` 是指路力度太大的样子。
  - `blobScene`：指路力度太小时那团看不出是猫的东西。
  - `land`、`flower`、`house`：① 里拿来练习的图。
- **去噪**：`a` 是雾的厚度，`blur = 16 * a`，所以先出轮廓、后出细节；③ 的围巾到后半段才出来。
- **高潮**：`buildClimax` 里 3600 个粒子，从铺满屏幕的雪花沿弯曲的轨迹飞到猫图的 60×60 格子上。落地前配乐抽空一下，然后砸下。
