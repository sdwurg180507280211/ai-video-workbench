# 代码动画：待并入 opus-code-video 技能的教训

云端定时任务改不了 my-skills 仓库，新学到的先记在这里，用户定期并进技能（并完删掉对应条目）。

## 2026-10-24《AI 为什么会一本正经地胡说八道》（一本正经，每日定时任务第一支）

- **云端环境的 Python 库可能是空的。** 会话启动那行写"Python 库 有"，只检查了 `/opt/venv-video/bin/python` 在不在；这次 venv 里只有 pip，Pillow、numpy、mgaudio 的依赖都没装（setup 脚本的 pip 那一步大概没跑完就被缓存了）。开工检查要真的 `import PIL, numpy, scipy, librosa, pedalboard`；缺了就照 setup.sh 那行 `pip install` 补装（约 2 分钟）。
- **云端（无显卡）渲染必须设 `MG_GPU_ARGS="--no-sandbox --disable-gpu --disable-gpu-compositing"`。** render.mjs 默认的 SwiftShader 合成在镜头大幅缩放后，会让屏幕上一条横带连续一两秒显示两秒前的旧画面（关键帧连出时也会出现）。第一次整片渲染因此报废。纯软件合成没有这个问题，还快一倍多。建议把它写进 render.mjs 的无显卡默认值，或写进 云端/README 的渲染命令。
- **云端整片渲染很慢，运动模糊按帧开关**：8 次全采样在云端 3.1 秒/帧（2 分半的片要近 4 小时）。本片给 render.mjs 加了 `window.blurAt(t)`：页面说这帧不用模糊（镜头不动），就只截一张、重复写 8 次。只在镜头飞行和砸点开 8 次采样，0.37 秒/帧（加上上一条）。建议并进技能的 harness。
- **质检总览图要看完整片的每一格**：这次关键帧都是单独出的（干净），横带只在整片里出现，是在逐 2 秒抽帧的总览图里看出来的。
- **`Math.exp(很大的数) * 0` 是 NaN**：镜头抖动写成 `Math.exp(-(t - land) * 9) * (t >= land ? 1 : 0)`，在 land 之前算出 Infinity × 0 = NaN，整个镜头 transform 失效，画面停在世界原点。先判断条件，再算指数。
- **按绝对坐标画的小标签别用 `popper` 弹入**（老教训又踩了一次）：`popper(g, 0, 0, …)` 会以世界原点缩放，标签从远处飞进来。用 `appear`。
- **DeepSeek B 路会一直按"每秒 4 字"挑段长**：时间列写"说话时长 + 画面停顿"的估算、并在稿子里写明"节拍按配音自动排"，第 3 轮以后它就不再当必须改。第一稿就这样写，能省一轮。
- **审稿要求的事实细节要回原文核**：这次论文的生日例子是 DD-MM 写法（03-07 是 7 月 3 日），第 3 轮被 A 路挑出来。引用论文里的数字、日期，先打开原文确认格式。
- **贴纸动作对照表在写稿时就列**（剧本末尾"小团子要用的动作"）：这次只缺 1 个（16_举着写满的试卷），开工后一次就出好了。
- **定时任务的会话不许建 GitHub Release**（`gh api -X POST .../releases` 返回 403 "not permitted for this session type"）。`deliver.sh` 这一步在定时任务里走不通：成片只能在会话里用发文件交给用户，或者换别的交付方式。每日任务提示词第 7 步要改。
