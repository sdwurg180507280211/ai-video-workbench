# 代码动画选题清单（每日定时任务从这里取题）

系列：「小团子AI」AI 科普，贴纸科普风格，横屏 16:9，童声旁白「软萌团子」（语速 -4），逐句字幕。
每支片讲清**一个**机制，用一个日常类比撑住画面。片长按"讲没讲透"定，一般 100～150 秒。

状态只用：待做 / 在做 / 已做 / 暂停。定时任务取第一条「待做」；有「在做」的先接着做完。
「待做」少于 3 条时，任务自己补 3 条新题，补在表格末尾，并在通知里说明。
你想插队或换题，直接改这张表：把题挪到「待做」的最前面，或者把不想做的改成「暂停」。
