# AI 视频工作台

一个只在本机跑的网页，把做 AI 视频的几类做法、每个作品和手里的素材放在一处看：
每类做法画成一条制作流程，每一步写清谁做、用什么、花多少钱、还能怎么换（每条说法标了出处），
再加一块"还可以试试"，用来开新片的思路。

目前两类做法：

| 做法 | 怎么做 | 对应的 Skill |
|---|---|---|
| Opus 导演 + 视频模型 | Claude 写剧本、提示词、分段表，Seedance 生成写实画面，自带台词和口型 | `seedance-short-drama` |
| 纯 Opus 写代码 | 画面是网页逐帧渲染的 MG 动画，配乐用代码合成，旁白用豆包语音，不调视频模型 | `opus-code-video` |

两个 Skill 在 [my-skills](https://github.com/sdwurg180507280211/my-skills)。

## 剧本与制作资料

`AI视频/` 放每部作品的剧本、分镜、提示词、审稿和改稿记录，以及两篇 GitHub 项目调研，入口是 [AI视频/README.md](AI视频/README.md)。
素材、生成片段和成片仍在本机总文件夹，不进仓库。

## 运行

```bash
python3 studio.py                       # 默认读 ~/Downloads/AI视频，或环境变量 AI_VIDEO_ROOT
python3 studio.py --root <总文件夹> --port 8765 --no-open
```

只用 Python 标准库；短剧作品的视频时长要 `ffprobe`。默认只监听 127.0.0.1。

## 总文件夹怎么放

```
AI视频/
├── 工作台.json                 {"入行日期": "2026-10-17"}，首页显示"入行第 N 天"
├── 短剧/<剧名>/第1集/作品.json   短剧作品，目录照 seedance-short-drama 的项目模板
├── 技术解说/<片名>/作品.json     代码动画作品，目录照 opus-code-video 的工程模板
└── 共用/<素材库>/素材清单.md     有这个文件的文件夹当素材库，下面每个带 透明/ 的子文件夹是一组贴纸
```

`作品.json` 示例：

```json
{"类别": "代码动画", "风格": "贴纸科普", "标题": "按下回车之后的 1 秒", "简介": "…", "状态": "已完成",
 "日期": "2026-10-19", "成片": ["成片_v2.mp4"], "封面": ["封面.jpg"], "章节": ["读懂网址", "DNS 问路"],
 "用量": {"旁白": "270 字", "花费": "¥0"}}
```

`类别` 对应 `flows/<类别>.json`：一类做法的流程卡片、步骤（怎么做、动手试、还能怎么换）和"还可以试试"。加一类新做法，就加一份流程数据。

## 页面

- 首页：入行天数、两类做法的对比（成本、耗时、用到的模型、适合什么）、全部作品、素材预览。
- 每类做法：整条链路图，点一步看怎么做和替代方案；下面是这一类的作品和"还可以试试"。
- 短剧作品：角色、片段、成片（按剪辑表的时间条）、全部文件。
- 代码动画作品：看片，章节时间条，按配音时间戳同步显示字幕，三个关键数字。
- 素材库：透明底贴纸，点开看大图。

页面只读文件；唯一会写的是短剧的看片标记（`<作品>/5_审片/标记.json`）。

## 测试

```bash
python3 -B -m unittest discover -s tests -v
```

视频、配音、角色图和账号信息都在你自己的总文件夹里，不进这个仓库。
