# AI 视频工作台

做 AI 视频的大本营：一个只读的网页，打开就看到短剧和代码动画各做到哪，点进一部作品看角色照片和剧本。

- **首页**：作品墙，分「短剧」「代码动画」两组。每部作品一张卡片，只放标题、状态（进行中 / 暂停 / 已完成）和一排角色照片。进行中的排在前面。
- **作品页**：角色照片（点开看大图）、正式剧本（按剧本格式排版），已完成的作品再加成片播放。
- **只显示现行的东西**：归档、审稿记录、旧版提示词、实验片、没选中的片段一律不显示；没完成的作品不显示旧成片。

两类做法：

| 做法 | 怎么做 | 对应的 Skill |
|---|---|---|
| Opus 导演 + 视频模型 | Claude 写剧本、提示词、分段表，Seedance 生成写实画面，自带台词和口型 | `seedance-short-drama` |
| 纯 Opus 写代码 | 画面是网页逐帧渲染的动画，配乐用代码合成，旁白用豆包语音，不调视频模型 | `opus-code-video` |

两个 Skill 在 [my-skills](https://github.com/sdwurg180507280211/my-skills)。

## 剧本与制作资料

`AI视频/` 放每部作品的剧本、分镜、提示词、审稿和改稿记录，以及两篇 GitHub 项目调研，入口是 [AI视频/README.md](AI视频/README.md)。
素材、生成片段和成片仍在本机总文件夹，不进仓库。

## 运行

```bash
python3 studio.py                       # 默认读 ~/Downloads/AI视频，或环境变量 AI_VIDEO_ROOT
python3 studio.py --lan --no-open       # 同一局域网的电脑、手机也能打开，启动时会打印局域网地址
python3 studio.py --root <总文件夹> --port 8765
```

只用 Python 标准库（3.9 起）。在 Mac 上会用系统自带的 `sips` 给角色照片缩小图，其他系统直接给原图。网页不写任何文件。

## 作品.json

每个作品文件夹放一个 `作品.json`，工作台只认这个文件（`归档/`、`node_modules/` 下的不扫）：

```json
{
  "类别": "短剧",
  "标题": "先听她说",
  "状态": "进行中",
  "日期": "2026-10-20",
  "角色": [
    {"名字": "林悦", "照片": "2_素材/角色/林悦_三视图.png", "位置": "左"},
    {"名字": "小团子", "照片": "../../共用/小团子AI素材/参考_角色A.png"}
  ],
  "剧本": {"文件": "AI视频/短剧/能不能不切/剧本.md", "章节": ["正式剧本"], "截止": "**制作要求**"},
  "成片": ["6_成片/xxx.mp4"]
}
```

- `状态` 只用三个词：进行中、暂停、已完成。每次做完一段工作由 Claude 更新，网页不自己猜。
- `角色.照片` 相对作品文件夹，可以指到总文件夹里的别处；没有照片就只写名字，显示首字。`位置` 是方形头像从哪边裁（左 / 中 / 右），三视图的胸像在最左边，写「左」。
- `剧本.文件` 以 `AI视频/` 开头的从本仓库读，其余相对作品文件夹。`.md` 只取 `章节` 里列的二级标题（按开头匹配，不写就整篇），读到以 `截止` 开头的行就停；`.txt` 每行一句旁白。剧本里的 `**角色名**` 换行接台词排成对白，`{台词}`、`<音效>` 会高亮。
- `成片` 只在状态是「已完成」时显示，取列表里第一个存在的文件。

总文件夹里的 `工作台.json`（`{"入行日期": "2026-10-17"}`）让首页显示「入行第 N 天」。

`flows/` 是第一版里讲解每类做法的流程数据，页面已经不用，留着备查。
